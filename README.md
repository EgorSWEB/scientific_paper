# Использование дистилляции знаний для стилизации изображений

Файлы для работы с моделью-учеником находятся в папке `fgist/STTR`, и обучение с тестированием запускается через файл `demo_sttr_image_ACCV.py`. В параметрах parser передаем `--testing`, если хотим просто протестировать чекпоинт, предвариительно добавив его в папку checkpoint_model с именем checkpoint0005.pth (входные данные в `inputs/content_test` и `inputs/style_test`), а без `--testing` запуститься обучение (входные данные в `inputs/content`, `inputs/style` и `inputs/target`). Также можете изучить параметры parser, в котором можно указывать нужную конфигураци. (distill_loss_type - 'Gatys' - лосс авторов, distill_loss_type - 'Gatys_2' - настоящий Гатис лосс, также имеются "MSE" и "MAE" соответственно).  
Файлы для работы с моделью-учителем находятся в папке `siid/StyleID`, и генерация картинок запускается через файл `run_styleid.py`. Более подробно описано в самой папке.
