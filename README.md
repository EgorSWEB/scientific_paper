# Использование дистилляции знаний для стилизации изображений

Файлы для работы с моделью-учеником находятся в папке `fgist/STTR`, и обучение с тестированием запускается через файл `demo_sttr_image_ACCV.py`.
Файлы для работы с моделью-учителем находятся в папке `siid/StyleID`, и генерация картинок запускается через файл `run_styleid.py`.
